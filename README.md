# ROAD TO CHAMPION — 운영 안내

TEAM APEX · TEAM 04 / WINTER SCREEN / 2027-01-16

## 미리보기
압축을 풀고 index.html을 브라우저로 열면 모든 메뉴가 작동합니다. 인터넷 연결이나 별도 설치가 필요 없습니다. 별도로 제공되는 단일 HTML 미리보기도 같은 화면을 표시하지만 게시용 원본은 이 폴더입니다.

## 무료 게시 (기존 GitHub 계정 사용, 명령어 불필요)
1. GitHub에서 `road-to-champion`이라는 새 **Public** 저장소를 생성합니다. 기존 모임 저장소는 건드리지 않습니다.
2. 저장소의 Add file → Upload files에서 `index.html`, `style.css`, `data.js`, `logic.js`, `app.js` 5개 파일을 올리고 Commit changes를 선택합니다.
3. 저장소 Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save. 배포 완료 시 Pages 화면에서 실제 주소를 확인합니다. 예상 주소 형식은 `https://계정명.github.io/road-to-champion/`입니다. 실제 발급 주소는 Pages에서 확인 전까지 확정되지 않습니다.
4. 확인된 주소를 카카오톡에 공유합니다. 로그인 없이 방문할 수 있습니다. Public 저장소와 사이트의 선수명, 스코어, 사진 등은 링크 외부에도 공개될 수 있으므로 게시 전 팀원 동의를 확인하고 민감한 내용은 올리지 않습니다.

## 운영 방식
- 카톡 인증/스코어/일정을 관리자만 ChatGPT에 전달합니다.
- 새 채팅이라면 현재 `data.js` 또는 최신 원본 ZIP을 함께 첨부합니다. 게시된 GitHub 저장소에 ChatGPT 연결 권한이 있는 경우 해당 파일을 직접 읽고 업데이트할 수 있습니다. 연결/권한이 없으면 수정된 data.js를 동일한 저장소에 덮어 올립니다. 기존 사이트 주소를 유지합니다.
- 기존 기록은 그대로 두고 신규 기록에 고유 id를 부여합니다. 오기 정정과 일정 변경은 대상 id를 유지하며 변경합니다. 정정 내역이 필요하면 note에 기록합니다.
- 동일한 인증과 스크린 라운드는 같은 sessionId로 관리합니다. 같은 날 별개의 실제 세션은 서로 다른 sessionId를 부여합니다. sessionId가 없으면 동일 선수/날짜/종류와 점수·코스 또는 시간·메모로 중복을 추정합니다. 애매하면 관리자가 확인해야 합니다.
- 기준 파 미제공 기록은 총타수와 라운드 횟수만 표시합니다. 평균 오버파는 최근 5회 모두의 파가 확인되어야 계산합니다. 사진·장소·시간 등도 확인된 데이터만 입력합니다.
- 모의대회는 별도 집계합니다. 실제 연습 횟수에도 포함하려면 각 선수의 training에 모의 라운드를 한 번만 등록하고 중복 확인합니다. 모의대회 점수와 개인 스크린 통계를 자동 연동하지 않는 정책입니다.
- 성장왕은 비교 가능한 2명 이상 중 이번 주 스크린 라운드를 등록하고 최근 5회 기준 양의 개선 폭이 가장 큰 선수로 선정합니다. 연습왕은 주간 인증 횟수, MVP는 이번 주 최근 완료 모의대회의 Best 3 반영 홀 비중이 가장 높은 선수입니다. 동률은 공동 선정합니다.
- 동점 팀 포인트는 공동 순위 방식(예: 5,5,3,2,1)으로 정의합니다. 대회 최종 누적 포인트 동점 처리 규정은 미제공으로 표시합니다. 다른 팀의 실제 기록이 없는 모의대회에서 포인트는 산출하지 않습니다.
- 날짜는 서울 시간대 YYYY-MM-DD, updatedAt은 +09:00 포함 ISO 일시로 저장합니다. 일주일은 월요일~일요일, 당일 이후의 실적은 집계하지 않습니다.
- 최종 업데이트 일시는 실제 수정 시각으로 변경합니다. 원본 파일을 백업하고 GitHub 커밋 기록을 유지합니다.
- 인증 사진/선수 사진은 실제 제공된 파일을 `assets/` 아래에 올린 뒤 상대 경로로 data.js에 지정합니다. 실제 사진 제공 전에는 이니셜로 대체합니다.

## 계산 및 화면 검수
`test.cjs`는 제작 검증용이며 게시할 필요가 없습니다. 실제 초기 데이터에는 연습·모의대회·미션·공지 예시가 없습니다. 계산 테스트의 예시 수치는 메모리에서만 사용됩니다.

파일 역할: index.html(문서), style.css(디자인), data.js(원본 데이터), logic.js(통계), app.js(화면), test.cjs(검증).
